# Data provenance — Day 17 Drought Impact Analyzer

**Fetch date:** 2026-11-24 (drought + boundaries); 2026-11-23 (yield +
weather, via Day 16 — copied, not re-fetched).

## Source

- **Drought severity — U.S. Drought Monitor REST API**
  (`https://usdmdataservices.unl.edu/api/`, documented at
  `https://droughtmonitor.unl.edu/DmData/DataDownload/WebServiceInfo.aspx`).
  No key, no account. 8 calls total: 2 state-DSCI calls
  (`StateStatistics/GetDSCI`, aoi 19 = Iowa, 17 = Illinois,
  1/1/2000–12/31/2025) and 6 county calls
  (`CountyStatistics/GetDroughtSeverityStatisticsByAreaPercent`,
  aoi IA/IL, blocks 2000–2008, 2009–2017, 2018–2025). DSCI =
  1×D0 + 2×D1 + 3×D2 + 4×D3 + 5×D4 on exclusive shares (= D0+D1+D2+D3+D4
  on the API's cumulative columns), range 0–500. Attribution: "U.S.
  Drought Monitor (NDMC/USDA/NOAA)".
- **Yield — Our World in Data "Maize yields" (FAO data, CC BY 4.0)**,
  USA 2000–2025, 26 rows, t/ha. Copied from Day 16's committed raw file
  (`day-16-crop-yield-prediction/data/raw/maize_yields_owid.csv`,
  fetched 2026-11-23, HTTP 200, 368,479 B); the pipeline re-downloads
  from `https://ourworldindata.org/grapher/maize-yields.csv?country=USA`
  only if the copy is missing.
- **Weather — Open-Meteo ERA5 archive (CC BY 4.0)**, daily
  `temperature_2m_mean, temperature_2m_max, precipitation_sum`,
  Iowa (41.8780, −93.0977) + Illinois (40.6331, −89.3985) centroids,
  2000–2025. Copied from Day 16's committed raw JSONs (fetched
  2026-11-23, 9,497 days/state, 0 missing); the pipeline re-downloads
  from `https://archive-api.open-meteo.com/v1/archive` only if the copies
  are missing.
- **County boundaries — US Census Bureau via plotly datasets (public
  domain)**,
  `https://raw.githubusercontent.com/plotly/datasets/master/geojson-counties-fips.json`
  (HTTP 200, 3,216,816 B, 3,221 features, verified 2026-11-24). Fetched
  at chart time, cached locally, not committed.
- **Not used live:** USDA Quick Stats (roadmap suggestion) returns HTTP
  401 without an API key, so county-level yields are out of scope.
  NOAA GHCN-daily (Des Moines station) is the roadmap's "NOAA weather"
  cross-check; not fetched (Open-Meteo already supplies the same daily
  fields).

## Fetch outcome

All 8 USDM calls returned HTTP 200 on 2026-11-24. State DSCI: 1,357
weekly rows per state (2000-01-04 → 2025-12-30). County calls: ~46,000
rows per block per state. No retries needed, no 5xx. Yield + weather
replayed from the Day 16 copies (byte-identical to Day 16's committed
files). County GeoJSON fetched once at chart time (HTTP 200).

## Commit rule for data files

- Small raw data IS committed: files under 1 MB each (under 5 MB per day
  folder) are part of the deliverable — `.gitignore` must NOT exclude
  `data/`. Anything larger must be `.gitignore`d and regenerated by the
  pipeline; record how to re-fetch it here.
- Committed raw total: ~840 KB (2 state DSCI CSVs ~54 KB, yield CSV
  ~369 KB, 2 weather JSONs ~584 KB).
- NOT committed (git-ignored, documented here): `data/raw/dsci_counties_*.csv`
  (~24 MB total — re-fetch with `python -m src.data_pipeline --live`)
  and `data/raw/counties_geo.json` (3.2 MB — re-fetch at chart time with
  `python -m src.make_charts`).
- In `--offline` mode the county aggregates rebuild from the committed
  `data/processed/county_year.csv`, and `data_source.json` records
  `county_raw_available: false`.

## Manual validation (one metric, by hand)

- **Metric:** Iowa 2012 growing-season mean DSCI.
- **Method:** independent recomputation from `data/raw/dsci_iowa.csv`
  (filter MapDate weeks in Apr–Sep 2012, mean of DSCI) vs the committed
  `gs_dsci_mean_iowa` value in `data/processed/annual_drought_yield.csv`.
- **Result (tester, 2026-11-24):** hand-computed 204.15384615384616 vs
  committed 204.15384615384616 — **difference 0.0, exact match**
  (26 growing-season weeks). Recorded in
  `data/processed/data_source.json` under `manual_validation`.
