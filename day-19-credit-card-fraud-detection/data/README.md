# Data provenance — Day 19 Credit Card Fraud Detection

## Source

- **Dataset:** Credit Card Fraud Detection (ULB Machine Learning Group
  / Worldline), European cardholders, two days in September 2013.
- **Canonical host:** Kaggle (`creditcard.csv`) — requires an account /
  API key, which was not available, so Kaggle was NOT the fetch route.
- **Fetch route used:** Hugging Face dataset
  `RS2k03/creditcard-fraud-dataset`, file `creditcard.csv`, resolved at
  `https://huggingface.co/datasets/RS2k03/creditcard-fraud-dataset/resolve/main/creditcard.csv`
  — public, no key, no login. Accessed 2026-11-26; one HTTP GET, ~8 s.
- **Attribution:** Dal Pozzolo et al., ULB / Worldline. The V1–V28
  features are PCA components (confidentiality); Time is seconds since
  the first transaction; Amount is the transaction value in the
  cardholder's currency (treated as USD here, as in the literature);
  Class 1 = fraud. The dataset is distributed for research use; no
  licence file ships with the mirror, so this project cites the source
  and does not redistribute the raw file (see below).

## Fetch outcome

Download succeeded on the first attempt (HTTP 200). The pipeline
verifies the fingerprint after every download and refuses to build on
a mismatch.

## Commit rule for data files

- Small raw data IS committed: files under 1 MB each (under 5 MB per day
  folder) are part of the deliverable — `.gitignore` must NOT exclude
  `data/`. Anything larger must be `.gitignore`d and regenerated by the
  pipeline; record how to re-fetch it here.
- **This day's exception:** the raw file is 144 MB, so
  `data/raw/creditcard.csv` is git-ignored and NOT committed. It is a
  local-only cache, re-downloaded by
  `python src/data_pipeline.py --live` (one GET, fingerprint-checked).
  Committed data is the 9 processed tables in `data/processed/`
  (31 KB total): `data_source.json`, `class_summary.csv`,
  `amount_summary.csv`, `amount_hist.csv`, `model_metrics.csv`,
  `confusion_matrix.csv`,
  `threshold_sweep.csv`, `cost_curve.csv`, `pr_curves.csv`.
- **No synthetic data:** real data verified (see above), so no synthetic
  file exists anywhere in this day. `data_source.json` records
  `synthetic: false`.
- **Local cache note (2026-11-26):** the 144 MB raw file was moved out
  of `data/` to `~/workspace/day-19-data/creditcard.csv` before
  validate/push (the validator counts `data/` on disk). To re-run the
  pipeline `--offline`, copy it back to `data/raw/creditcard.csv`, or
  re-download it with `python src/data_pipeline.py --live`.
