# Data provenance — Day 03 Crypto Market Anomaly Detector

## Source

- **Provider:** CoinGecko public API (`https://api.coingecko.com/api/v3`).
- **Endpoint used:** `GET /coins/{coin}/market_chart/range?vs_currency=usd&from=1762473600&to=1794009600` for `bitcoin`, `ethereum`, `solana`. No `interval` parameter (granularity is automatic: >90 days → daily, 00:00 UTC).
- **Window:** 2025-11-07 → 2026-11-07 (365-day span, 366 daily observations per coin — both endpoint dates are included).
- **Access date:** 2026-11-07 (fetched by the coder, live).
- **Keyless vs key:** keyless — no API key was used. All three no-key calls returned **HTTP 200**. The optional Demo-key fallback (`COINGECKO_DEMO_API_KEY` environment variable, header `x-cg-demo-api-key`) is kept in `src/data_pipeline.py` but was not needed and no key is stored anywhere in the repo.
- **Fetch outcome:** live data, fetched live on 2026-11-07 (no key, HTTP 200). `data/processed/data_source.json` records `source: "live"`, `synthetic: false`, `seed: null`. No synthetic fallback was used, and no offline run overwrote the source field afterwards — the published `data_source.json` is the one written by the live run.

Each raw JSON holds `prices`, `market_caps` and `total_volumes` arrays of `[timestamp_ms, value]` pairs; the pipeline merges them on timestamp into `date, coin, price, market_cap, volume` plus the §4.1 features (`daily_return`, `abs_return`, `volume_ratio`, `log_volume_ratio`, `vol_30d_ann`, `drawdown`, `return_z`, `volume_z`, `vol_regime`). Flaggable universe: 1,005 rows (return_z is first valid on day 31 per coin; volume_z on day 60, because it needs 30 prior log-volume ratios). `data/processed/anomaly_timeline.csv` holds the 54 flagged days; `data/processed/injected_anomalies.csv` holds the 30 injected-anomaly labels; `data/processed/crypto_daily_injected.csv` is the evaluation copy with the injections applied (the real frame is never modified).

## Commit rule for data files

- Small raw data IS committed: files under 1 MB each (under 5 MB per day folder) are part of the deliverable — `.gitignore` must NOT exclude `data/`. Anything larger must be `.gitignore`d and regenerated by the pipeline.
- Raw file sizes: `bitcoin_market_chart.json` 39,951 bytes; `ethereum_market_chart.json` 40,155 bytes; `solana_market_chart.json` 39,836 bytes (total ~120 KB, well under the limit).
- Synthetic fallback output (`data/raw/*_synthetic.json`) is git-ignored and must never overwrite the live cache. No synthetic files were produced in this build.

## Licence / attribution note

CoinGecko data is free for use via the public API; **CoinGecko requires attribution** (API Terms Clause 3): **"Powered by CoinGecko"** (https://www.coingecko.com) appears on the dashboard, in the repo README and on every chart. Do not redistribute raw bulk data or re-host the API; the fetched series is cached locally for this project only. Code in this repo is MIT (see `LICENSE`); CoinGecko data is under separate CoinGecko terms, not MIT.

**Unresolved licensing tension (carried from Days 1–2, stated honestly):** CoinGecko API Terms Clause 6 bars selling, renting, leasing, sub-licensing, re-distributing or syndicating API access without an executed agreement; the Demo (free) plan does not include commercial rights, and attribution alone does not grant them. CoinGecko support defines redistribution as providing data / API access for others to retrieve and use beyond viewing it in the product, and says cached or reformatted data is not automatically exempt. However, **no CoinGecko page found states explicitly whether committing verbatim raw API JSON to a public GitHub repo counts as redistribution**, so this is unresolved and no legal certainty is claimed either way. Day 3 follows Days 1–2's rule and keeps the small raw JSONs committed as the provenance record.

## Manual validation (one metric, by hand)

**Ethereum 2026-08-20 return_z**, recomputed by hand from `data/processed/crypto_daily.csv` (and checked by `tests/test_pipeline.py::test_committed_timeline_recomputes_flag_return_z` to ≤1e-9):

- Daily return on 2026-08-20: **+0.174982 (+17.4982%)**.
- Trailing 30 daily returns before that day (2026-07-21 → 2026-08-19, excluding today): mean **0.000927**, sample standard deviation (ddof=1) **0.016059**.
- return_z = (0.174982 − 0.000927) / 0.016059 = **10.838289**.
- This matches `anomaly_timeline.csv` (`return_z = 10.838289024100378`) to a difference of 1.8e-15, i.e. ≤1e-9.
- The same hand check on volume_z gives 4.912121 (diff 1.2e-14), matching the timeline's 4.912121.
