# Data provenance — Day 05 Social Media Sentiment Analyzer

## Source

- Provider: **YouTube Data API v3**, endpoints `commentThreads.list`
  (top-level comments) and `comments.list` (replies — probed only, not used).
- Corpus: **12 videos, 12 distinct channels**, fixed by the researcher
  from Day 4's video frame (top-2 by comment count per Day 4 topic +
  top BI & Visualisation + next 3 overall, max 1 per channel).
- Window: **2025-11-09 → 2026-11-09** (post-fetch filter on `publishedAt`;
  the API offers no date filter for comments).
- Fetched live: **2026-11-09** via the `custom.youtube` connector
  (key in the connector, never in a file). Cost: **1 unit per call**.
- Quota used: **16 units** (most videos stopped after 1 page — the
  first page's oldest comment already predated the window start).
- Data from the YouTube Data API v3. YouTube data is under separate
  YouTube terms — see [YouTube's Terms of Service](https://www.youtube.com/t/terms).

## Manual validation (one metric, by hand)

Comment `UgzqOcwu85wLEKUGQ714AaABAg` (video `yZvFH7B6gKI`):
"Well detailed and straightforward! Thank you!"

Hand computation with the frozen lexicon (`src/sentiment.py`):

- Tokens: well, detailed, and, straightforward, thank, you.
- Scored words: detailed **+1**, straightforward **+1**, thank **+1**
  → word sum 3.0. (well / and / you are not in the lexicon.)
- Punctuation: two `!` → +0.25 each, capped at +0.5 → **+0.5**
  (raw sum is positive, so the bonus applies).
- No negation, no intensifier, no emoji in this comment.
- Raw sum s = 3.0 + 0.5 = **3.5**.
- Compound = s / √(s² + 15) = 3.5 / √(12.25 + 15) = 3.5 / √27.25
  = 3.5 / 5.2202 = **0.6705**.
- 0.6705 ≥ 0.05 → **positive**; scored words **3**.

`comments.csv` records exactly this: `sentiment_score` 0.6705,
`sentiment` positive, `scored_words` 3. ✓ Verified by hand.

## Commit rule for data files

- Small raw data IS committed: files under 1 MB each (under 5 MB per day
  folder) are part of the deliverable — `.gitignore` must NOT exclude
  `data/`. Anything larger must be `.gitignore`d and regenerated by the
  pipeline; record how to re-fetch it here.
- Synthetic fallback output goes to `data/raw/*_synthetic.json` only
  (git-ignored) and never overwrites the live cache.
