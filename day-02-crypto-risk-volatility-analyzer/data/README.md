# Data provenance — Day 02 Crypto Risk & Volatility Analyzer

## Source

- **Provider:** CoinGecko public API (`https://api.coingecko.com/api/v3`).
- **Endpoint used:** `GET /coins/{coin}/market_chart/range?vs_currency=usd&from=1762387200&to=1793923200` for `bitcoin`, `ethereum`, `solana`. No `interval` parameter (granularity is automatic: >90 days → daily, 00:00 UTC).
- **Window:** 2025-11-06 → 2026-11-06 (365-day span).
- **Access date:** 2026-11-06 (fetched by the coder, live).
- **Keyless vs key:** keyless — no API key was used. All three no-key calls returned **HTTP 200**. The optional Demo-key fallback (`COINGECKO_DEMO_API_KEY` environment variable, header `x-cg-demo-api-key`) is kept in `src/data_pipeline.py` but was not needed and no key is stored anywhere in the repo.
- **Fetch outcome:** live data, originally fetched live on 2026-11-06 (no key, HTTP 200). `data/processed/data_source.json` currently records `source: "cache"` because the processed files were regenerated offline from the committed cache (`--offline`); the underlying data is still that live fetch — `synthetic: false`, `seed: null`. No synthetic fallback was used.

## Commit rule for data files

- Small raw data IS committed: files under 1 MB each (under 5 MB per day folder) are part of the deliverable — `.gitignore` must NOT exclude `data/`. Anything larger must be `.gitignore`d and regenerated by the pipeline.
- Raw file sizes: `bitcoin_market_chart.json` 39,950 bytes; `ethereum_market_chart.json` 40,154 bytes; `solana_market_chart.json` 39,837 bytes (total ~120 KB, well under the limit).
- Synthetic fallback output (`data/raw/*_synthetic.json`) is git-ignored and must never overwrite the live cache. No synthetic files were produced in this build.

## Licence / attribution note

CoinGecko data is free for use via the public API; **CoinGecko requires attribution** (API Terms Clause 3): **"Powered by CoinGecko"** (https://www.coingecko.com) appears on the dashboard, in the repo README and on every chart. Do not redistribute raw bulk data or re-host the API; the fetched series is cached locally for this project only. Code in this repo is MIT (see `LICENSE`); CoinGecko data is under separate CoinGecko terms, not MIT.

**Unresolved licensing tension (carried from Day 1, stated honestly):** CoinGecko API Terms Clause 6 bars selling, renting, leasing, sub-licensing, re-distributing or syndicating API access without an executed agreement; the Demo (free) plan does not include commercial rights, and attribution alone does not grant them. CoinGecko support defines redistribution as providing data / API access for others to retrieve and use beyond viewing it in the product, and says cached or reformatted data is not automatically exempt. However, **no CoinGecko page found states explicitly whether committing verbatim raw API JSON to a public GitHub repo counts as redistribution**, so this is unresolved and no legal certainty is claimed either way. Day 2 follows Day 1's rule and keeps the small raw JSONs committed as the provenance record.

## Manual validation (one metric, by hand)

**Bitcoin max drawdown**, recomputed by hand from `data/processed/crypto_daily.csv` (and checked by `tests/test_pipeline.py::test_committed_daily_recomputes_btc_max_drawdown` to ≤1e-9):

- Peak price in the window: **$105,951.50 on 2025-11-11**.
- Trough price after the peak: **$58,566.09 on 2026-07-01**.
- Max drawdown = 58,566.09 / 105,951.50 − 1 = **−0.447237 (−44.7237%)**.
- This matches `crypto_risk_summary.csv` (`max_drawdown = −0.4472367620754484`) and the drawdown column in `crypto_daily.csv` (price / running max − 1) to ≤1e-9.
- Peak-to-trough: 2026-07-01 − 2025-11-11 = **232 days**. The coin never closed at or above $105,951.50 again by 2026-11-06, so it is **not recovered** (128 days elapsed since the trough).
