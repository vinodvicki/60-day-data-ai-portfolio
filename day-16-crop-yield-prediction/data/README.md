# Data provenance — Day 16 Crop Yield Prediction

## Source

- **Yields:** FAO via Our World in Data — `https://ourworldindata.org/grapher/maize-yields.csv?country=USA`
  (CC BY 4.0). USA maize yield, tonnes per hectare, 2000–2025.
- **Weather:** Open-Meteo ERA5 archive — `https://archive-api.open-meteo.com/v1/archive`
  (CC BY 4.0). Daily `temperature_2m_mean`, `temperature_2m_max`,
  `precipitation_sum` for the Iowa centroid (41.8780, −93.0977) and the
  Illinois centroid (40.6331, −89.3985), 2000-01-01–2025-12-31,
  timezone America/Chicago. Keyless; 3 HTTP calls total (1 yield + 2 weather).
- **Not used live, and why:** USDA Quick Stats API returns HTTP 401 without
  an API key (a key needs a free USDA signup) — so FAO/OWID national yields
  stand in for the roadmap's suggested source. NOAA GHCN-daily was verified
  reachable (HTTP 200) as a cross-check only. The US Drought Monitor
  statistics download needs an interactive form; drought is Day 17's subject.

## Fetch outcome

Live fetch on 2026-11-23, all 3 calls HTTP 200 on the first attempt. No
retries needed, no synthetic data (`synthetic: false` in
`data/processed/data_source.json`).

## Row counts and coverage

- Yields: 26 USA rows (2000–2025), 0 missing. 2024 = 11.253324 t/ha,
  2025 = 11.705214 t/ha.
- Weather: 9,497 days per state (2000–2025 incl. leap years), 0 missing
  values in any of the three daily fields.
- Joined: 26 rows — 20 train (2000–2019) + 6 held-out (2020–2025).
- Features per year are the Iowa/Illinois average of the growing-season
  (Apr–Sep) aggregates. 1 t/ha = 15.932 bu/acre for corn
  (39.368 bu per tonne ÷ 2.47105 acres per hectare).
